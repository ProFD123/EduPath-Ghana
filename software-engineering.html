Software Engineering

Software Engineering focuses on designing, developing, testing and maintaining software systems.

About the Programme

Software Engineering applies systematic engineering principles to the development of reliable and maintainable software.

Students learn programming, software design, testing, databases, development methods and software project management.

Main Areas of Study

Programming Software Design Web Development Database Systems Software Testing Algorithms Mobile Development Software Project Management
